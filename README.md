# 👗 نظام إدارة مبيعات الفساتين النسائية

## 📋 نظام متكامل احترافي لإدارة الطلبات والأرباح

تطبيق احترافي يجمع بين تطبيق جوال (Android) وتطبيق ويب (Windows) لتتبع مبيعات الفساتين النسائية مع حساب الأرباح وإدارة المردودات والتقارير الشهرية.

---

## 🎯 المميزات الرئيسية

### 📱 تطبيق الجوال (Android)
- ✅ إضافة طلبات جديدة بسهولة
- ✅ تتبع حالة الطلبات (جديد - موجل - واصل - راجع)
- ✅ تنبيهات يومية الساعة 8 مساءً بصوت ونص
- ✅ عرض الأرباح الفورية
- ✅ واجهة سهلة وسلسة
- ✅ مزامنة فورية مع قاعدة البيانات

### 💻 تطبيق الويب (Windows)
- ✅ لوحة تحكم متقدمة وشاملة
- ✅ إدارة جميع الطلبات والمنتجات
- ✅ تقارير شهرية شاملة
- ✅ رسوم بيانية للأرباح والمردودات
- ✅ إدارة ملفات Excel
- ✅ تحليلات متقدمة

### 🔄 التكامل والمزامنة
- ✅ قاعدة بيانات موحدة (MongoDB)
- ✅ مزامنة فورية بين الجوال والويب
- ✅ تحديث ملفات Excel تلقائياً
- ✅ حفظ النسخ الاحتياطية

## 📊 معادلة حساب الأرباح

```
✅ الربح = (سعر البيع) - (5000 أجور التوصيل)

حالات الطلب:
🟦 جديد: تم إدخال الطلب في النظام
🟨 موجل: الطلب بانتظار التوصيل
🟩 واصل: وصل للزبون ✅ (يتم حساب الربح)
🟥 راجع: تم إرجاع الطلب (لا ربح)
```

## 🛠️ التقنيات المستخدمة

### Backend
- **Node.js + Express.js** - API قوي وسريع
- **MongoDB** - قاعدة بيانات مرنة
- **JWT** - المصادقة الآمنة
- **Node-Cron** - المهام المجدولة
- **ExcelJS** - معالجة ملفات Excel

### Frontend Web
- **React.js** - واجهة مستخدم حديثة
- **Tailwind CSS** - تصميم جميل
- **Chart.js** - رسوم بيانية احترافية
- **Redux** - إدارة الحالة

### Mobile
- **React Native** - تطبيق واحد لجميع الأجهزة
- **Redux** - إدارة الحالة
- **Push Notifications** - الإشعارات
